# Online Cinema Ticket Booking Management System

## Project Overview

The Online Cinema Ticket Booking Management System is a software application designed to allow users to browse movies, view available shows, select seats and book cinema tickets online.

The system helps cinema administrators manage movies, theatres, show timings, seat availability, bookings and payments efficiently.

## Objectives

- Allow users to browse available movies
- Display movie details and show timings
- Display available seats
- Allow users to select seats
- Provide online ticket booking
- Manage booking details
- Manage movie and theatre information
- Track seat availability
- Maintain booking history
- Generate booking confirmation
- Reduce manual ticket booking

## Main Modules

1. User Registration and Login
2. Movie Management
3. Theatre Management
4. Show Management
5. Seat Management
6. Movie Search
7. Ticket Booking
8. Payment Management
9. Booking History
10. Admin Management
